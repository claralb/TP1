# TP1
Trabalho Prático 1  - Tower Defense - Projeto desenvolvido para a disciplina de Computação Gráfica.

## Sobre o jogo
 Galinhas vs Raposas é um jogo do estilo Tower Defense. 
 
   O jogador deve proteger o galinheiro, localizado no centro da cenário, contra o ataque das raposas. 
    As raposas surgem das laterais da tela e se encaminham para o galinheiro. Para impedir para que elas alcancem o galinheiro e matem as galinhas, o jogador deve construir novas torres, as quais possuem galinhas atiradoras que jogam seus ovos nas raposas para causar danos, outra maneira de causar danos é clicando nas raposas.
  A dificuldade aumenta com o tempo, pois as raposas passam a aparecer com maior frequência.
